<samp>一个建筑向的大社区社交 Minecraft 服务器，目标：非常杰出。</samp>

- 正在为 8 月开服冲刺 🚀

### 🔗 TLeaf-Link

<samp>基于 Velocity + Bukkit 的 QQ ↔ Minecraft 跨服互通机器人，Fork 自 PlumBot 并重度二次开发。</samp>

- QQ ↔ MC 实时聊天桥接、进离服/切服通知
- QQ 群内一键点击回复 MC 玩家
- @ 用户显示群名片、群级别转发开关
- 开源持续开发中 &nbsp;·&nbsp; **[查看仓库 →](https://github.com/LinyeFL/TLeaf-Link)**
