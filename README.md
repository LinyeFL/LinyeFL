### 🔗 [TLeaf-Link](https://github.com/LinyeFL/TLeaf-Link)

> QQ ↔ Minecraft 跨服互通机器人，重度二次开发自 PlumBot。

- QQ ↔ MC 实时聊天桥接、进离服/切服通知
- 群内一键点击回复 MC 玩家 · 群级别转发开关
- @ 用户显示群名片 · MC 物品展示与死亡信息转发（开发中）
- AGPL 3.0 开源，持续迭代
